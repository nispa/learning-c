# Passo Passo

Impara a programmare un passo alla volta, direttamente nel browser.
Ogni livello chiede una piccola modifica a un programma: lo esegui, vedi l'output e un
controllo automatico ti dice se è giusto, con spiegazioni chiare.

Oggi il corso copre il **C**: variabili, cicli, funzioni, array, stringhe, puntatori,
memoria dinamica, strutture e preprocessore (81 livelli in 12 capitoli).

## Usarlo

Apri `index.html` nel browser. I progressi restano salvati nel browser.
Il corso è in italiano e in inglese (si cambia dalle Impostazioni): interfaccia, livelli e messaggi d'errore.

## Svilupparlo

```sh
npm test
```

Le regole del progetto (per persone e agenti) sono in [AGENTS.md](AGENTS.md); come aggiungere livelli o un nuovo
linguaggio è spiegato in [src/languages/README.md](src/languages/README.md).
